# VisualMiner

VisualMiner is an intelligent analytics & visual mining platform built with React, Vite, and Tailwind CSS.

## Project Structure

```
VisualMiner/
└── frontend/      # React (JavaScript) + Vite + Tailwind CSS application
```

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running Locally

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack
- **Framework:** React 19 (JavaScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
